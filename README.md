## 🚀 我的项目

### 🏛️ [古代热搜辟谣局](https://github.com/V-Giotto/ancient-hot-search-debunk)

> 古人上热搜，真相由你查。

把历史传闻放进现代社交平台，让用户从刷热搜开始，走进真正有依据的历史查证。

《古代热搜辟谣局》是一款互动历史科普 Web 应用：用热搜榜、发现页、好友聊天和「我的」收藏，把严肃史料做成可刷、可聊、可查证的跨时空社交体验。用户先吃瓜、再判断真假，最终看到准确说法与可核验来源；AI 历史人物可对话讨论，但真假判题与史料边界由服务端固定，不由模型临场发明。

- **核心创意：** 用社交媒体的吸引力，让玩家主动走进历史证据
- **技术栈：** Next.js / React / TypeScript，像素风界面
- **荣誉：** 🏅 **2026 青年 AI 黑客松二等奖**
